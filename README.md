# 📊 Statistical Modeling Projects – MITx MicroMasters

This repository contains a collection of **statistical modeling projects** developed as part of **MITx 6.419x: Data Analysis – Statistical Modeling and Computation in Applications**, a core course in the **MITx MicroMasters Program in Data Science and Statistics**.

Each project applies real-world data and statistical computation to address complex analytical problems, demonstrating both **theoretical understanding** and **practical implementation** in Python.

---

## 🧠 Projects Overview

### 📁 `CAVIAR_criminal_network_analysis.ipynb`
Analyzes a criminal network dataset using the **CAVIAR** (Clustering and Visualizing Relationships) algorithm to infer hidden connections between suspects.  

**Key methodologies:**
- Probabilistic Graphical Models  
- Bayesian Inference  
- Expectation–Maximization (EM) Algorithm  
- Network Analysis & Visualization  

---

### 📁 `Clustering_and_hierarchical_structure_in_cell_types_using_gene_expression_profile.ipynb`
Identifies structure and clusters in high-dimensional **gene expression** data to classify cell types.  

**Key methodologies:**
- Principal Component Analysis (PCA)  
- Hierarchical Clustering  
- Gaussian Mixture Models (GMM)  
- Heatmap & Dendrogram Visualization  

---

### 📁 `Ocean_flow_around_Philippines_Archipelago.ipynb`
Explores **ocean current dynamics** around the Philippines Archipelago using spatial statistical techniques.  

**Key methodologies:**
- Spatial Statistical Analysis  
- Vector Field Visualization  
- Principal Component Analysis (PCA)  
- Correlation Analysis of Flow Patterns  

---

### 📁 `Time_series_prediction_of_CO2_emission_in_Mauna_Loa_Inflation_rate_of_US_economy.ipynb`
Performs **time series modeling** to predict CO₂ emissions at Mauna Loa and U.S. inflation rates.  

**Key methodologies:**
- Time Series Decomposition (Trend, Seasonality, Residual)  
- Autoregressive Integrated Moving Average (ARIMA)  
- Forecast Evaluation (AIC/BIC, Residual Analysis)  
- Stationarity Testing (ADF Test)
